# Agent knowledge

Durable project insights for future agents, one entry per line. Keep this list in sync with the
folder (check with `go run ./.agent/scripts/index-check`). Not here: judgment calls awaiting the
owner (docs/DEFAULTS.md, local only) and work to do (docs/PLAN.md).

- [rembed-spike-numbers.md](rembed-spike-numbers.md) — bge-small via rembed: ~0.2 s per search, ~33 ms/chunk to index; int8 is slower on Apple Silicon.
- [rembed-model-cache-and-downloads.md](rembed-model-cache-and-downloads.md) — rembed downloads only for hub ids; kb loads from `<cache>/<org>--<name>` so search never downloads.
- [sqlite-round-midpoints.md](sqlite-round-midpoints.md) — use `round(x*10^d)/10^d` in stats SQL; SQLite `round(x,d)` differs from DuckDB at midpoints.
- [macos-bsd-sed-in-tests.md](macos-bsd-sed-in-tests.md) — no GNU `sed -i` (or other GNU flags) in tests; use Go (cli tests: `useFakeEditor` sets deps.editor).
- [go-dot-dirs-ignored.md](go-dot-dirs-ignored.md) — `./...` skips `.agent/`; run and test helpers by explicit path.
- [sqlite-vec-cgo-warnings.md](sqlite-vec-cgo-warnings.md) — sqlite-vec's `sqlite3_auto_extension` deprecation warnings on macOS are harmless.
- [go-no-mcdc-tool.md](go-no-mcdc-tool.md) — no Go MC/DC tool; MC/DC dropped 2026-10-29 for statement coverage + branch-outcome tables + fuzz properties; reqproof (closed beta) evaluated, not adopted.
- [vec0-width-is-lazy.md](vec0-width-is-lazy.md) — chunks_vec exists only after EnsureEmbedMeta(dim>0) at FLOAT[dim]; handle "no such table"; tests may use any width.
- [signal-notifycontext-needs-ctx-everywhere.md](signal-notifycontext-needs-ctx-everywhere.md) — NotifyContext swallows SIGINT; calls that ignore ctx make Ctrl-C a no-op.
- [wave-end-pass-boundary-audit.md](wave-end-pass-boundary-audit.md) — limits were tested only above, never at; grep constants + cover profile to find gaps.
- [sqlite-deferred-tx-locked.md](sqlite-deferred-tx-locked.md) — deferred `BeginTx` bypasses busy_timeout in WAL; concurrent `kb add` gets "database is locked"; use `_txlock=immediate`.
- [mutation-survivor-patterns.md](mutation-survivor-patterns.md) — symbol-relative constants, fast-path `<=` checks and driver-only error paths, guarded comparisons, error-return sentinels and message args survive mutation without being test gaps; `-diff` results before 2026-10-29 are unreliable.
- [reindex-prune-rediscover.md](reindex-prune-rediscover.md) — `reindex --all` prunes only rows that a second Discover after ListEntries also misses; a concurrent `kb add` is otherwise deleted.
- [sqlite-cancel-surfaces-as-interrupt.md](sqlite-cancel-surfaces-as-interrupt.md) — a cancel can surface as sqlite3.ErrInterrupt or sql.ErrTxDone, not context.Canceled; sqlite.wrap decides by ctx.Err(); and a pinned *sql.Conn runs statements (even COMMIT) on an already-cancelled ctx, so check ctx.Err() before COMMIT.
- [store-seam-and-errs.md](store-seam-and-errs.md) — store interfaces vs sqlite backend, errs at boundaries, cli/report.go owns messages and exit codes 0/1/2/3; deps for test seams.
- [workspace-root-discovery.md](workspace-root-discovery.md) — a location is the nearest .kb/kb.toml (or --root/--global), the store is --store else default_store; only kb init creates either; cli tests chdir into a made location.
- [config-package-and-precedence.md](config-package-and-precedence.md) — internal/config schema, single loader (cli.loadConfig), precedence flag/--set > store config > defaults, reserved keys, no env vars except $EDITOR.
- [named-stores-layout-notes](named-stores-layout-notes.md) — why stores live in .kb/stores/<name>, named stores use data-<name>/, and migrate needs a flock around backup+apply
- [search-settings-and-trace.md](search-settings-and-trace.md) — [search] reaches kb search as search.Settings (Params + EffectiveJSON hash); zero Settings = defaults; search_defaults.golden pins default ranking bit for bit; config caps keep scores finite and vec0 k ≤ 4096.
- [sqlite-fixture-dump-quirks.md](sqlite-fixture-dump-quirks.md) — dumping kb SQLite files as text fixtures: contentless FTS5 via shadow tables, vec0 via its columns (huge preallocated blobs, unmarked shadow table, sqlite_sequence), VACUUM INTO needs a writable handle.
- [capped-file-reads.md](capped-file-reads.md) — a stat size check is not a cap: /dev/zero symlinks and FIFOs bypass it; refuse non-regular files, then read through io.LimitReader (config.readCapped).
- [explain-bm25-columns](explain-bm25-columns.md): Searcher.Explain re-scores candidates one bm25 column at a time; columns bracket the total (max <= total <= sum), never add up; explain does not log.
- [render-budget.md](render-budget.md): kb search's human output comes from internal/render (greedy elastic levels, ceil(runes/4) tokens); search.Hit carries no summary or updated date, so the CLI looks them up per hit.
- [embedding-cache-wiring](embedding-cache-wiring.md): `deps.newEmbedder` wraps embedders with `embed.Cached`; `execute` closes the cache files and prints late warnings once the command returns.
- [explicit-migration-policy.md](explicit-migration-policy.md) — durable files migrate only via `kb migrate up`: Open refuses older (before WAL), Apply upgrades, backups go through .partial, harness loadfixture makes old databases.
- [store-sources.md](store-sources.md) — a store indexes only its explicit [[sources]] (none = nothing); test configs must carry the data/ source; globs use internal/glob; symlinks out of the root are skipped.
- [go-fuzz-shell-gotchas.md](go-fuzz-shell-gotchas.md) — zsh passes an unquoted two-flag variable as one argument; a short fuzz run with 18 workers can end in "context deadline exceeded" with no crasher: rerun with -parallel 8
- [eval-gold-and-metrics.md](eval-gold-and-metrics.md) — kb eval: gold from store.JudgedLog (useful verdicts on path+heading; opens a separate variant), other stores' gold counted apart and never scored, ScoreRanking credits a gold item once, seeded PCG bootstrap; min_judged is the small-sample caveat; baselines (versioned JSON in <store>/eval, refused not migrated), Compare (paired bootstrap delta + exact sign test), and --sweep (Prepare once, seeded SHA-256 holdout split, min_judged gate, one QueryMemo for vector reuse, overfit flag); 6.4: replays as of each search's ts with the prior from one prepared read, [prior] sweep keys behind a strict gate.
- [eval-replay-leakage.md](eval-replay-leakage.md) — eval replays with the prior/memory run as of the newest search's ts AND leave out the query's own searches: eval gold is a union over the query's searches, so asOf alone would leak gold into the evidence; "own" means every same-key search of the log the prior reads, not just the --since/--caller window.
- [cross-store-merge.md](cross-store-merge.md) — fan-out search merges per-store fused ranks (1/(rrf_k+r)), identity (root, path, ord), ties primary then canonical ref; log/caps key by (store, chunk) and (root, path); worker panics are handed back (errs.WorkerPanic) to exit 3.
- [staticcheck-is-a-module-tool](staticcheck-is-a-module-tool.md) — run `go tool staticcheck -tags fts5 ./...`; never `go run …@latest`
- [float-sums-sort-first](float-sums-sort-first.md) — sort terms before summing when results must be bit-identical for any order
- [exact-identifier-list.md](exact-identifier-list.md) — identifier fields of a query also search chunks_exact (v6, tokenchars `_-.:/`, no porter/diacritic folding) as a third RRF list; every write path fills it; v6 also keys search_opens by store.
- [e2e-journeys-framework.md](e2e-journeys-framework.md) — E2E (L7, built) = stdlib cram-style transcript runner over a harnessfake binary with a `KB_HARNESS_NOW` clock; testscript rejected (update only via `cmp`, new dep); E2E owns cross-command flows only.
- [context-budget-frame.md](context-budget-frame.md) — `kb context` budgets the whole Markdown (frame included) by re-rendering with a smaller render budget; budget 1 is the floor.
- [synonyms-query-expansion.md](synonyms-query-expansion.md) — `synonyms.txt` expands query terms into `("a" OR "b")` via `FTSQuery.Alts` on the main FTS list only; format, lookup order, hash, the dropped-term rule.
- [spell-and-synonym-suggest.md](spell-and-synonym-suggest.md) — spell adds the closest common vocabulary term as an FTS alternative only below 3 rows (OR stays OR, first-run rows kept); `kb synonyms suggest` mines one-word rewrites from the log and never writes the file.
- [edges-tags-aliases.md](edges-tags-aliases.md) — v7: edges (path|wikilink, NULL = dangling) resolved by store.EdgeResolver after every reindex, entry_tags (trimmed lowercase) behind the tag filter, aliases in the FTS title column.
- [stale-listing.md](stale-listing.md) — `kb stale`: no date, old (age >= --days, UTC calendar days, verified else updated), superseded, broken path link; exit 0; clock injected.
- [related-supersede-neighbors.md](related-supersede-neighbors.md) — `Related` CTE walk (depth 1..3, both ways, each edge once, RelatedModel twin), post-fusion supersede penalty (Superseded on Retriever, explain + `superseded` hit flag), `--neighbors` as a render-only Related: section.
- [feedback-prior-wiring.md](feedback-prior-wiring.md) — the prior's gate, evidence times (feedback/open ts, asOf), order vs supersede, v8 `prior` log columns (NULL = inactive), `[prior]` in the settings hash, per-search `Judged` cost (≈ 32 ms read + 4 ms index at 10k judged searches), `search.Evidence`/`prior.Index` (read once, slice by asOf, equal to Build bit for bit), `Request.ExcludeEvidence`, damaged log ts = Conflict, the pure `rememberedGold`/`memoryRowsOf` split.
- [phrase-near-tier.md](phrase-near-tier.md) — phrase/NEAR(8)/AND tiers of the main FTS list (`phrase_boost`): one list, tier per row logged in v9 `fts_tier`, rows rescored by AND, OR only when AND is empty, literal words only; untiered oracle golden; keep `+f.rowid` in the ChunkIDs query (10x).
