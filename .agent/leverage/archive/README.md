# Archived leverage points

Entries that stopped being high-leverage weak points: the area was refactored or redesigned so
the weakness is gone, the code was removed, or something else outranked it. They're kept as a
record of what was tracked, why, and how it was resolved.

To archive: move the file here with `git mv` (or `mv` while it's untracked), set **Status** to
`retired (<reason>, <date>)`, add a **Resolution** line (what changed, and the PR, item or wave),
remove its line from `../index.md` and add it below. An archived entry that becomes relevant
again is moved back and re-reviewed.
