# .agent

Shared workspace for agents working on kb. The rules for using it are in the repo-root
`AGENTS.md` (section "The .agent folder"). In short:

- `scripts/` — reusable helper scripts; `scripts/index.md` lists them.
- `knowledge/` — durable project insights; `knowledge/index.md` lists them.
- `state/` — temporary per-run agent logs (git-ignored); see `state/README.md`.
